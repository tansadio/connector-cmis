This module is the base for Odoo modules implementing different
integration scenario with a CMIS server. It allows you to configure a
CMIS backend in Odoo.

It provides a lightweight client for the CMIS 1.1 browser binding
(`odoo.addons.cmis.client`) covering navigation, folders and documents,
queries, content streams and versioning. It has been tested with Alfresco
Community 26.2.
